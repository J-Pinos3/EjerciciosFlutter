# Cinemapedia APP in Flutter
## I learned with the Flutter Course of Fernando Herrera.

### The technical features of this app are:
- Principles Of Clean Architecture
- Isar Database
- Dio for HTTP Requests
- Riverpod
- AutomaticKeepAliveClientMixin In Order To Keep Alive The State When The User Uses Custom Bottom Navigation Bar
- Search Delegate
- TheMovieDB API


### In this app the user can:
- Watch New Movies Info
- Watch Top Rated Movies Info
- Watch The Information Of The Chosen Movie, It Includes: Categories And Actors
- Watch All Popular Movies
- Watch Your List Of Favorite Movies
- Search Movies
